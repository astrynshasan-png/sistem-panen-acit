# Sistem Panen Acit

## Deskripsi
Program sederhana untuk menghitung total hasil panen dan menghitung
harga setelah diskon, dibuat sebagai tugas mata kuliah Algoritma
Pemrograman.

## Cara Menjalankan
1. Pastikan Python sudah terpasang
2. Jalankan perintah:
   python hitung_panen.py
3. Program akan menampilkan total hasil panen dalam kg
